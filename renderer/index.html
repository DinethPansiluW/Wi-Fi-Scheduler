About Wi-Fi OFF Scheduler

Schedule Wi-Fi disconnect, connect and IP renew - even when the app is closed.

Wi-Fi OFF Scheduler v1.0.0

Windows desktop app that replaces the original batch-script tool. Uses the built-in Windows netsh and Task Scheduler tools, so your schedules keep running after you quit. No data leaves your computer.

CORE TECHNOLOGIES & LICENSES
  • Electron: cross-platform desktop runtime, MIT License.
  • electron-builder: packaging and installer tooling, MIT License.
  • Windows netsh + Task Scheduler: built-in Windows components used for Wi-Fi control and background schedules.
